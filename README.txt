1. Создай на github.com новый репозиторий (New repository).
2. Нажми "uploading an existing file" и перетащи ВСЁ содержимое этой папки,
   включая скрытую папку .github (важно: путь .github/workflows/build.yml должен сохраниться).
3. Открой вкладку Actions -> дождись зелёной галочки (3-6 минут).
4. Открой запуск -> внизу Artifacts -> скачай pvphud-jar (zip) -> внутри будет pvphud-1.0.0.jar.
5. Положи .jar в папку mods вместе с Fabric API для 1.21.4.
